## 📌 Sobre o Projeto

O presente projeto tem como objetivo demonstrar a importância da **perícia computacional** na investigação de crimes envolvendo dispositivos eletrônicos e evidências digitais.

Durante o desenvolvimento do projeto, serão abordadas as principais etapas do trabalho pericial, desde a **identificação, coleta, isolamento e acondicionamento** adequado dos equipamentos, até a **preservação da integridade das evidências** e sua posterior **análise técnica**.

Dessa forma, o projeto busca evidenciar como a correta manipulação, preservação e documentação dos vestígios digitais são fundamentais para garantir a confiabilidade das evidências, preservar sua integridade e contribuir para a identificação da materialidade do crime e, quando possível, de seus responsáveis.

---

## 🧭 Metodologia

O projeto será desenvolvido seguindo as etapas fundamentais da perícia computacional:

| Etapa | Descrição |
|:-----:|:----------|
| 1️⃣ **Identificação** | Reconhecimento dos dispositivos e possíveis evidências digitais relacionadas ao caso. |
| 2️⃣ **Preservação** | Adoção de procedimentos para evitar alterações ou perda das evidências. |
| 3️⃣ **Aquisição e Coleta** | Obtenção dos dados utilizando técnicas e ferramentas apropriadas. |
| 4️⃣ **Análise Forense** | Investigação dos dados coletados em busca de informações relevantes para o caso. |
| 5️⃣ **Documentação** | Registro detalhado dos procedimentos realizados, resultados obtidos e evidências encontradas. |
| 6️⃣ **Elaboração do Relatório** | Organização das informações e apresentação das conclusões da investigação. |
